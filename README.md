完成全部步骤后，你可以在微信里：

```
你: "去巡逻一圈"

你: "现在室温多少"

你: "找一下我的钥匙在哪"
车: [全屋巡逻 → YOLO扫描 → 找到→拍照]"在茶几上"

你: "把这杯水送到书房"
车: [你把水放车上 → 导航到书房 → 到站播报]
```
